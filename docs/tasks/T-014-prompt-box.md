## 목표

모든 화면에 들어가는 **프롬프트 칸 컴포넌트 하나**. 각 화면은 자기 문맥만 넘긴다. 기능 화면
묶음은 프롬프트 칸을 따로 만들지 않는다.

## 소유 경로

- `web/src/app/assistant/` (T-010 셸 소유에서 빠진 폴더)

`web/package.json` 은 T-010 소유다. 패키지가 필요하면 매니저에게 요청한다.

## 내용

- 화면 문맥 훅: 화면이 `{ area, sample_id?, run_id?, region?, ... }` 를 등록한다. 이름은 T-010 셸이
  정한 훅 이름을 따른다.
- 질문 입력, 스트리밍 답변, 도구 호출 표시, 답변마다 사용 토큰.
- 제안 카드: 설명, 대상 명령, 예상 게이트 판정, 확인 / 거부 버튼. 원격 보기 (읽기 전용) 에서는
  버튼이 꺼진다. 확인 뒤 진행은 엔진 이벤트로 보여 준다.
- 같은 대화 기록을 모든 화면에서 이어 본다 (대화 id).
- 연결 안 됨 상태 (키 없음, 공급자 fake) 를 분명히 표시한다. 가짜 공급자일 때 "fake" 표시.
- Claude 가 낸 숫자는 "model" 로 구분 표시. 판정은 공통 판정 컴포넌트 (T-010) 를 쓴다.
- UI 문구는 영어.
